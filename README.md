# Terraria-DS
Terraria-DS 0.2.0  Unofficial fan project for dual-screen Android handhelds such as the AYN Thor. It is not made by or connected with Re-Logic. This app does not include Terraria. You need your own copy of Terraria for PC, using the files from its Linux or Mac version.  This is an early test version. ZIP and folder import have not been fully tested
